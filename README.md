# Hamza Ahmed Khan — Web Developer Portfolio

A modern, high-performance responsive portfolio built with pure HTML5, CSS3, and vanilla JavaScript. Designed without heavy frameworks to ensure lightning-fast load times, complete custom styling, and smooth UI animations.

---

## 🚀 Key Features

* **Interactive UI Effects:** 3D tilt interaction on hero code card, interactive cursor glow, and dynamic background elements.
* **Smooth Animations:** Scroll reveal triggers, scroll progress tracking bar, and animated skill meters.
* **Project Showcases:** High-fidelity UI mockups for projects including SAVOR Restaurant and Traffic Light Controller.
* **Credentials Section:** Certificate cards featuring Google Gemini Certified Student recognition.
* **Fully Responsive:** Optimized touch navigation and custom layouts for mobile, tablet, and desktop views.
* **Zero Dependencies:** Pure web standards with no build step required.
